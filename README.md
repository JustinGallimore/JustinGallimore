## Portfolio Projects

### [sailpoint-jml-pipeline](https://github.com/JustinGallimore/sailpoint-jml-pipeline)
End-to-end Joiner-Mover-Leaver automation pipeline built in SailPoint IdentityNow (ISC). Uses a CSV-based HR source delivered over SFTP, with all three lifecycle workflows live-tested and validated. Includes a 73-step walkthrough with embedded screenshots covering the full pipeline from source configuration through provisioning and access removal.

**Key areas covered:** source configuration, lifecycle state mapping, workflow triggers, access profiles, SFTP integration, and end-to-end JML testing.

---

### [zero-trust-conditional-access](https://github.com/JustinGallimore/zero-trust-conditional-access)
Conditional Access policy design and enforcement lab in Microsoft Entra ID. Includes sanitized policy exports, break glass account monitoring via KQL, and PowerShell scripts using the Graph API for real-time policy auditing.

**Key areas covered:** Conditional Access policy design, named locations, MFA enforcement, break glass account alerting, and Graph API automation.

---

### [sailpoint-ad-provisioning-pipeline](https://github.com/JustinGallimore/sailpoint-ad-provisioning-pipeline)
Active Directory provisioning pipeline built on SailPoint ISC with IQService running on Windows Server 2022. Covers the full connector setup, TLS configuration, account schema mapping, and automated AD account creation and deactivation driven by identity lifecycle events in SailPoint.

**Key areas covered:** IQService installation and TLS binding, AD connector configuration, account attribute mapping, provisioning policy design, and end-to-end lifecycle-driven AD provisioning.

---

### [Delinea-PAM-Implementation-with-Vaulting-JIT](https://github.com/JustinGallimore/Delinea-PAM-Implementation-with-Vaulting-JIT)
PAM implementation lab built on Delinea Secret Server and Windows Server 2022. Covers credential vaulting, privileged session launch via RDP, and Just-In-Time access workflows with full audit logging — the core capabilities a PAM engineer would be expected to configure and validate in a production rollout.

**Key areas covered:** Secret Server installation and configuration, credential vaulting, RDP session proxying, JIT access policy design, and audit log review.

---

### [IAM-Metrics-Audit-Portfolio](https://github.com/JustinGallimore/IAM-Metrics-Audit-Portfolio)
Two-phase identity audit and reporting project.

**V1** covers on-premises Active Directory with PowerShell-based stale account detection, access enumeration, and CSV reporting.

**V2** migrates reporting to Microsoft Entra ID using the MS Graph API and Power BI for visual access analytics and sign-in log analysis. Includes a documented credential exposure incident (hardcoded client secret) with full remediation steps covering secret rotation, commit history cleanup, and process improvement.

**Key areas covered:** AD audit scripting, MS Graph API integration, Power BI data modeling, credential hygiene, and incident response.

---

### [sailpoint-governance-program](https://github.com/JustinGallimore/sailpoint-governance-program)
Enterprise-grade governance program built in SailPoint ISC. Covers RBAC design, Separation of Duties policy configuration, access certification campaigns, and SOX audit evidence reporting — the full governance stack a compliance team would expect to see in a regulated environment.

**Key areas covered:** role design and RBAC modeling, SoD policy configuration, certification campaign setup, reviewer workflows, and audit-ready evidence reporting.
